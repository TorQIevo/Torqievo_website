Torqievo — Website Design System

Status: Final
Brand: Torqievo
Design Direction: Premium / Modern Technology
Primary Visual Identity: Soft Lavender + Warm Ivory Cream
Design Philosophy: Premium, modern, trustworthy, technical, clean, approachable
Implementation Rule: This document is authoritative. Do not introduce alternative colors, typography, gradients, shadows, spacing systems, or visual styles unless explicitly required by the project.

⸻

1. Brand Overview

Torqievo  is a modern technology company focused on:

* Web application development
* Mobile application development
* Application rebuilding and modernization
* Technical support
* Technical consulting
* End-to-end software engineering solutions

The website must communicate:

* Technical expertise
* Reliability
* Modern engineering
* Premium quality
* Innovation
* Simplicity
* Professionalism
* Trust

The website must not feel:

* Corporate and outdated
* Overly playful
* Neon/futuristic
* Cyberpunk
* Excessively purple
* Generic SaaS
* Visually cluttered
* Excessively animated

⸻

2. Primary Design Direction

The selected design direction is:

Premium

The visual identity combines:

* Soft technology lavender
* Warm ivory cream
* Deep charcoal
* Light lavender surfaces
* Controlled violet accents
* Large clean typography
* Generous whitespace
* Subtle shadows
* Rounded but professional components

The overall appearance should feel similar to a premium technology consultancy/product studio, rather than a generic software development agency.

5. Color Usage Ratio

The website should approximately follow this visual distribution:

60%  Warm Ivory / Neutral backgrounds
25%  White / elevated surfaces
10%  Lavender
5%   Dark / strong accent elements

The exact percentage can vary by section, but lavender must remain an accent, not the entire visual identity.

Do not create a website where most sections are purple.

Gradients are allowed but must be subtle.

Primary Brand Gradient

linear-gradient(135deg, #8B7CF6 0%, #6C5CE7 100%)

Use for:

* Primary CTA buttons
* Hero decorative elements
* Selected brand graphics
* Occasional visual highlights

Do not use this gradient everywhere.

⸻

Soft Lavender Gradient

linear-gradient(135deg, #E9E6FF 0%, #F8F6F0 100%)

Use for:

* Hero backgrounds
* Feature backgrounds
* Large decorative surfaces

The gradient must remain extremely subtle.

Gradient Restrictions

Do NOT introduce:

* Rainbow gradients
* Neon gradients
* Blue-to-purple gradients
* Pink-to-purple gradients
* Green gradients
* Orange gradients
* Dark cyberpunk gradients

The Torqievo visual identity is based on lavender + warm ivory.

42. Design Do’s

Always:

* Use warm ivory as the primary background
* Use lavender as the recognizable Torqievo accent
* Use deep charcoal for important text
* Use generous whitespace
* Use subtle borders
* Use soft shadows
* Use consistent rounded corners
* Keep layouts clean
* Keep visual hierarchy strong
* Maintain professional spacing
* Keep animations subtle
* Prioritize readability
* Use consistent iconography

⸻

43. Design Don’ts

Never:

* Replace the brand palette with blue
* Introduce random colors
* Use neon purple
* Use cyberpunk styling
* Use excessive gradients
* Use excessive glassmorphism
* Use heavy black shadows
* Use random border colors
* Use multiple font families
* Use random font sizes
* Use overly rounded/pill-heavy UI
* Use excessive animations
* Make every section purple
* Use pure white as the dominant page background
* Create a completely different visual style for individual pages

46. Final Implementation Rule

This file is the single source of truth for the Torqievo website visual design.

The implementing agent must NOT make independent visual decisions when this document already specifies the required behavior.

If a component is not explicitly described:

1. Use the existing TORQIEVO color tokens.
2. Use Inter typography.
3. Use the existing border-radius system.
4. Use the existing shadow system.
5. Use the existing spacing system.
6. Follow the Premium design direction.
7. Prefer simplicity and whitespace.
8. Do not introduce new colors.
9. Do not introduce new fonts.
10. Do not introduce a competing visual style.

When uncertain, the implementation should choose the simplest option that remains consistent with this design system.

The final website should feel like one unified Torqievo product—not a collection of independently designed sections.
